# Animation experiment instructions

- This directory is an experimental workspace. Do not silently integrate experimental work into the main game.
- The user does not plan to install Blender. Use the browser-ready GLB/glTF showcase and browser-based experiments; the original .blend and optional conversion scripts are archival, not the active prerequisite.
- Record every research/experiment session in LEARNING_LOG.md, including failures, settings, evidence, uncertainties, decisions, and future integration implications.
- LEARNING_LOG.md is append-only. Corrections belong in a new dated entry referencing the earlier entry.
- Use stable AT-XXX experiment IDs and the experiment template where useful. Do not mark a proposed experiment as tested or visually accepted.
- Follow the root AGENTS.md requirement to append the session's changes and validation to UPDATES.md as well.
